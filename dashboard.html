📱 Install Guide (if a Play Protect popup appears)

  1. Tap the button above — the APK will download (shown in notifications)
  2. Open the APK. If it asks for "Install unknown apps": Settings → Allow from this source (browser/File Manager) → back → Install
  3. If a Play Protect warning appears → More details → Install anyway (this is your OWN app — 100% normal)
  4. ⚠️ Seeing "Blocked by Play Protect" with no Install anyway button? → Open the Play Store app → top-right profile photo → Play Protect → ⚙️ Settings → turn OFF "Scan apps with Play Protect" → install the APK → ✅ done → then turn Play Protect back ON
  5. Still blocked? Open the APK with Airplane mode ON (the online check fails = direct install), or open the APK from the Files/File Manager app (not Chrome)
  6. Done ✅ — Parent Monitor on your phone, Child app on the child's phone. Then pair it from this dashboard

Note: the child app appears as a normal "Battery Health" utility app — install it on the child's phone with confidence.
💡 Easiest way (Setup Wizard): the Child APK button above gives you the FG Setup wizard — install it on the child's phone and it downloads + installs the real child app from inside (no browser or Play Protect hassle). Wizard: Download → Install → Open → pairing code.
