📱 Install guide (Play Protect wala popup aaye to?)

  1. Upar button dabao — APK download ho jayega (notification me dikhega)
  2. APK kholo. "Install unknown apps" maange to: Settings → Allow from this source (browser/File Manager) → wapas → Install
  3. Play Protect warning aaye → More details → Install anyway (ye tumhari APNI app hai, 100% normal)
  4. ⚠️ "Blocked by Play Protect" aaye aur Install anyway NAHI dikhe? → Play Store app kholo → top-right profile photo → Play Protect → ⚙️ Settings → "Scan apps with Play Protect" OFF → ab APK install karo → ✅ ho jayegi → phir Play Protect wapas ON kar dena
  5. Phir bhi na lage? Airplane mode ON karke APK kholo (online check fail = seedha install), ya Files/File Manager app se APK kholo (Chrome se nahi)
  6. Ho gaya ✅ — tumhare phone par Parent Monitor, child phone par Child app. Phir yahin dashboard se pair karo

Note: child app apne aap ek "Battery Health" jaisa normal utility app dikhta hai — child phone par aaram se install karo.
💡 Aasaan tarika (Setup Wizard): upar wala Child APK button FG Setup wizard deta hai — use child phone par install karo, wizard ke andar se asli child app download + install ho jayegi (browser/Play Protect ka chakkar nahi). Wizard: Download → Install → Open → pairing code.
